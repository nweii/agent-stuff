# obsidian-clis

The canonical skill is in [Obsidian Tools](../../plugins/obsidian-tools/skills/obsidian-clis/). This folder is a navigation pointer, not an installable skill.

Individual named installs use the repository’s local Claude catalog (tested with skills CLI 1.7.0). Existing-lock relocation requires 1.5.24 or later:

```bash
bunx skills add nweii/agent-stuff --skill obsidian-clis
```

The individual archive remains [`zips/obsidian-clis.zip`](../../zips/obsidian-clis.zip).
